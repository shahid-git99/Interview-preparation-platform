# PrepIQ — AI-Powered Interview Training Platform

> Internship project · Full-stack · Python + MongoDB + Gemini + Vanilla JS

PrepIQ lets candidates build a profile, then takes a personalised AI-powered mock interview generated by **Google Gemini**, and receives structured feedback immediately after.

## ⚡ Setup & Run

### 1. Clone / extract the project
```bash
cd prepiq
```

### 2. Set up the Python environment
```bash
cd backend
python -m venv venv

# Activate:
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Configure environment variables
```bash
# From the project root:
cp .env.example .env
```

Open `.env` and fill in:

```env
MONGO_URI=mongodb://localhost:27017   # or your Atlas URI
DB_NAME=prepiq
SECRET_KEY=<generate with: python -c "import secrets; print(secrets.token_hex(32))">
GEMINI_API_KEY=<your key from https://aistudio.google.com/app/apikey>
```

### 4. (Optional) Seed the database
```bash
cd backend
python seed.py
```

### 5. Start MongoDB
```bash
# If installed locally:
mongod --dbpath ./data
# Or just make sure MongoDB is running as a service.
```

### 6. Start the backend
```bash
cd backend
uvicorn main:app --reload --port 8000
```

API docs available at: **http://localhost:8000/docs**

### 7. Open the frontend
Open `frontend/pages/index.html` directly in your browser, or serve with any static server:
```bash
# Python quick server (from project root):
python -m http.server 5500 --directory frontend/pages
# Then visit: http://localhost:5500
```

> **Important:** The frontend calls `http://localhost:8000` for API requests. Make sure the backend is running before using the app.

## 🔑 Getting a Gemini API Key

1. Go to [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. Sign in with your Google account
3. Click **Create API key**
4. Copy and paste it into your `.env` as `GEMINI_API_KEY`

> Without a key, the app still works in **fallback mode** — it uses generic questions and gives basic feedback. Gemini is required for personalised, dynamic interviews.

## 🌐 API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/auth/signup` | Register new user |
| POST | `/auth/login` | Login, get JWT |
| POST | `/profile/setup` | Save profile + upload resume |
| GET | `/profile/me` | Get current user's profile |
| POST | `/interview/start` | Generate questions, create session |
| POST | `/interview/submit` | Submit answers, trigger AI evaluation |
| GET | `/interview/feedback/{id}` | Get feedback for a session |
| GET | `/interview/sessions` | List all past sessions |

All protected routes require `Authorization: Bearer <token>` header.

## 🚀 Production Notes

- Replace `allow_origins=["*"]` in `main.py` with your actual frontend domain
- Use MongoDB Atlas for a hosted database
- Store `SECRET_KEY` in a secrets manager (not just `.env`)
- Serve the frontend via Nginx or deploy to Netlify / Vercel
- Run the FastAPI backend on a cloud VM or deploy to Railway / Render
